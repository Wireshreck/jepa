⬡ jepa109M text JEPA · one rotation · Platonic Representations

Two JEPAs that never saw a pair learn the same world, up to one rotation.

This machine serves the 109M-parameter text JEPA of “Proving and Improving the Platonic Representation Hypothesis with JEPAs” (Balestriero & LeCun, 2026) — the architecture whose headline result is beating Qwen2.5-72B and Llama-3-70B on cross-modal alignment. Official checkpoints are restricted, so this install trained the exact architecture locally, on this computer, with the paper’s own code (good views + LeJEPA). Everything runs on your CPU.

Try it

Find photos by description

Your description goes through the text JEPA, then through the one fitted rotation, and lands next to photos that the frozen DINOv2 (a vision model trained with no captions at all) had embedded. No network here was ever trained on an image–caption pair; the pairs only fit the rotation.

The model’s neighbourhood

Enter text; the model embeds it into its 768-dim world space and shows the nearest captions of the COCO test set (in its own space) or photos (through the rotation). A trained JEPA puts two captions of one scene together — the good views it grew up on.

Alignment benchmarks

Measured on this machine with the repository’s own protocol, next to the paper’s reported numbers. Compare honestly: the paper’s flagship encoder saw ~900 million captions on 16 GPUs; this local one has been training on a tiny slice of that compute.
